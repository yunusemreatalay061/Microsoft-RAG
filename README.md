# 🤖 Microsoft RAG Assistant

Bu proje, belgeleriniz üzerinden akıllı ve hızlı yanıtlar almanızı sağlayan **Retrieval-Augmented Generation (RAG)** tabanlı bir yapay zeka asistanıdır. **Streamlit** arayüzü sayesinde kullanımı son derece kolay ve etkileşimlidir.

---

## ✨ Özellikler

- 📄 **Belge İşleme & İndeksleme:** Yüklenen belgeleri analiz eder ve vektör veritabanına aktarır.
- 🔍 **Akıllı Arama (RAG):** Sorduğunuz sorulara en alakalı kaynak metinleri bularak doğru yanıtlar üretir.
- 💻 **Kullanıcı Dostu Arayüz:** Streamlit ile geliştirilmiş sade ve hızlı web arayüzü.
- 💬 **Soru-Cevap & Geçmiş:** Bağlamı koruyarak sorularınıza tutarlı cevaplar verir.
